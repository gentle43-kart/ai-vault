# 규정·해설 요약 — 민원유형 → 적용조문 → 방어 관점
 
> 출처: 「방송심의에 관한 규정」(방통심의위규칙 제150호, 2020.12.28.) + 해설집(2016).
> **현행 여부 확인 필요**: 규칙 제150호가 최신 개정본인지, 답변 작성 전 국가법령정보센터로 확인 권장.
> 사용법: 민원의 주장에서 위반유형을 식별해 해당 행의 조문·해설 취지·방어 관점을 검토의견 논증의 뼈대로 삼는다.

## A. 심의 대상·요건 (전제 판단)
 
| 조문 | 내용 | 실무 포인트 |
|---|---|---|
| 제3조① | 방송 등의 내용이 공정성·공공성·공적책임을 유지하는지 심의 | 심의 대상 범위 |
| **제3조②** | **보존기간(6개월) 경과 방송은 심의하지 않음** (단, 허위 방송·명백한 사실 왜곡으로 심의 필요하고 확보 가능한 경우 예외) | 6개월 경과 민원의 근거. "민원접수 당시" 문구 필수 |
| 제4조① | 방송·유통 후 사후 심의·의결 | 사전심의 아님 |
| 제5조 | 심의 기본원칙: 매체·채널별 창의성·자율성·독립성 존중, 전문성·다양성 차이 고려, 사회통념 존중 | 매체·장르별 특성 고려의 규정상 근거 |
 
## B. 공정성·객관성 (일반기준 제1·2절) — 시사·보도 민원의 핵심
 
| 조문 | 규정 | 방어 관점(해설 취지) |
|---|---|---|
| 제9조① | 진실을 왜곡하지 아니 | 논평·평가는 왜곡이 아님. 의혹 '전달'은 단정 아님 |
| 제9조② | 대립 사안에서 공정성·균형성 유지, 당사자 의견 균형 반영 | 균형성 = 양적 균등 아님(판례 【1】). 상반 견해 병행 시 충족 |
| 제10조 | 사실보도와 해설·논평 구별 | 논평 코너는 사실보도와 다른 잣대 |
| 제13조 | 대담·토론의 형평성·균형성·공정성, 대립 견해 참여 합리적 보장 | 대담 형식은 완화된 심사(판례 【1】【3】) |
| 제14조 | 객관성: 정확·객관적, 불명확 내용을 사실인 것처럼 방송 금지 | 다의적 해석 여지·양측 입장 전달 시 위반 아님 |
| 제16조 | 통계·여론조사 고지사항 | 이미 공표된 복수 조사 추이 인용은 조사의뢰자·일시만 고지 가능(제2항) |

## 심의 절차 관련 (참고)
- 위원회는 「방통위법」 제25조·「방송법」 제32조 등에 근거해 **실제 방송된 내용**을 심의(제작과정·유튜브 게시물 등 소관 밖).
- 매체·장르별 특성 고려 의무(제5조) → **타 채널 제재사례 유무만으로 위반 단정 불가**.

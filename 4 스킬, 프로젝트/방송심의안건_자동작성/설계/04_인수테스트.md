# 04. 설치·실행 인수 테스트

작성: 2026-11-25 · 대상: 방송심의 안건 자동작성 P0 · 기준: [03_상세기술설계서.md](03_상세기술설계서.md)

결과 칸에는 `PASS / FAIL / 미실시(이유)`와 날짜를 적는다. 실행하지 않은 항목은 완료로 보지 않는다.

## A. 기본 시험

| 번호 | 시험 | 절차 | 통과 기준 | 결과 |
|---|---|---|---|---|
| A1 | 환경 점검(첫 설치) | `안건자동작성_점검.cmd` 더블클릭 | Python 3.12·faster-whisper·av<19·FFmpeg·한글 COM이 모두 "정상", 창이 닫히지 않고 결과를 보여 줌 | 미실시 |
| A2 | 작업 만들기 | `agenda.py new` (견본 영상, 조항·구간·쟁점) | `output\<작업ID>\job.json` 생성, 입력값 그대로 | 미실시 |
| A3 | 핵심 업무 1회 | 스킬로 "이 영상으로 안건 만들어줘" → prepare → 초안 → fill | 전사·캡처·context·draft·HWP가 모두 생기고, HWP가 한글에서 열림 | 미실시 |
| A4 | 결과 품질 | A3 결과를 담당자가 확인 | 인용 발언이 해당 시각의 실제 발언과 같음, 결론 문장 없음, 양식 서식 유지 | 미실시 |
| A5 | 재실행·데이터 유지 | A3 작업으로 `prepare` 다시 실행 | 전사·캡처를 건너뛰고 기존 결과 유지. `--force`일 때만 다시 처리 | 미실시 |
| A6 | 원본 보존 | A3 뒤 양식 원본·엑셀 원본 확인 | 수정 시각·내용이 그대로 | 미실시 |

## B. 오류 상황

| 번호 | 상황 | 통과 기준 | 결과 |
|---|---|---|---|
| B1 | 없는 영상 경로 | 입력 오류 메시지, 종료 코드 2, 폴더를 만들지 않음 | 미실시 |
| B2 | 구간이 영상 길이를 넘음 | 오류 안내 또는 영상 끝까지로 자르고 알림 | 미실시 |
| B3 | 전사 실패(예: 음성 없는 구간) | 캡처·사례·context는 생성, 실패가 log에 기록 | 미실시 |
| B4 | 한글 COM 실패(한글을 강제 종료한 상태 등) | draft.md 보존, 한글 정리, 실패 안내 | 미실시 |
| B5 | 사례 CSV 열 불일치 | 사례 단계만 실패, 없는 열 이름 표시 | 미실시 |
| B6 | 같은 작업 동시 실행 | 두 번째 실행이 `.lock` 안내 후 종료 | 미실시 |
| B7 | 사용자가 열어 둔 한글 | fill 뒤에도 사용자 한글 문서가 그대로 열려 있음 | 미실시 |

## C. Windows 실행 파일

| 번호 | 항목 | 통과 기준 | 결과 |
|---|---|---|---|
| C1 | CRLF 줄바꿈 | `.cmd`가 CRLF로 저장됨 | 미실시 |
| C2 | 인코딩 | 한글 메시지가 깨지지 않음(`chcp 65001`) | 미실시 |
| C3 | 한글 경로 | `J:\AI 자료\4 스킬, 프로젝트\…`에서 동작 | 미실시 |
| C4 | Python 탐지 | `py -3.12` 없으면 안내 후 멈춤 | 미실시 |
| C5 | 오류 시 창 유지 | 오류가 나도 `pause`로 창이 남음 | 미실시 |

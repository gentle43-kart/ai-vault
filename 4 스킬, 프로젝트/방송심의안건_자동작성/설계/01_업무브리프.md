## 3. 실행 형태 — 하이브리드 [설계 제안]

| 맡는 쪽 | 하는 일 | 이유 |
|---|---|---|
| Python 스크립트 | 음성 추출(FFmpeg), 전사(faster-whisper, 타임코드), 쟁점 구간 화면 캡처, CSV 사례 검색, HWP 양식 채우기(한글 COM) | 규칙·기계 작업. 반복 가능하고 AI가 필요 없음 |
| Claude 스킬 | 사용자 입력 확인, 쟁점 구간의 전사·캡처 판독, 방송내용·적용 사유 문장 작성, 사례와의 차이 정리 | 문장 작성·판독은 AI가 유리. 로컬 AI 불필요하므로 모델 선택 기능은 넣지 않음 |

독립 프로그램(화면·모델 선택)은 기각: 로컬 AI와 여러 사람 사용이 필요 없어 구축 비용만 늘어난다.

## 4. AS-IS → TO-BE

| 단계 | AS-IS(사람) | 구분 | TO-BE |
|---|---|---|---|
| 1 | 영상 시청, 쟁점·조항 정함 | 사람 판단 유지 | 그대로. 사용자가 조항·구간·쟁점을 입력 |
| 2 | 쟁점 구간 발언 받아 적기 | 자동화 가능 | 스크립트: 전사(구간 지정 가능) |
| 3 | 장면 캡처 | 자동화 가능 | 스크립트: 쟁점 구간 캡처(간격 지정) |
| 4 | 같은 조항 사례 찾기 | 규칙으로 가능 | 스크립트: CSV에서 조항·키워드로 검색 → 후보 표 |
| 5 | 방송내용·적용 사유 작성 | AI 보조 유용 | Claude: 전사·캡처·사례를 보고 초안 작성(결론은 쓰지 않음) |
| 6 | 양식에 옮겨 적기 | 자동화 가능 | 스크립트: 선택한 HWP 양식의 지정 위치에 입력 후 저장 |
| 7 | 검토·수정 | 사람 판단 유지 | 그대로. 타임코드·인용 발언 대조표를 함께 제공 |

원칙: 전사·캡처 결과는 파일로 먼저 저장(AI 실패와 무관), 영상 전체를 AI에 넣지 않고 쟁점 구간만 넘김, 과거 의결 결론을 정답처럼 옮기지 않음.

## 5. 자료 저장 형식 [설계 제안]

| 자료 | 형식 | 비고 |
|---|---|---|
| 심의의결 내역 | 원본 xlsx 보존 + 변환 CSV | 의결결과와 의결이유는 다른 열. 실제 열 구성은 견본 필요 [TODO] |
| 심의규정 | 조항별 MD + front matter(조항·시행일·버전) | 원문과 해설 분리, 개정 전후 구분 |
| 안건양식 | 유형별 HWP 여러 개 + `template_config.json`(양식별 입력 위치) | 입력 위치 표시 방식(누름틀·표 칸 등)은 양식 견본을 봐야 정함 [TODO] |
| 작업 결과 | `output\<영상이름>\` 아래 전사(SRT·JSON), 캡처, 사례 후보, 초안 MD, 완성 HWP | 다시 실행해도 기존 결과를 지우지 않음 |

## 6. 범위 (초안)

- **P0:** 구간 전사, 구간 캡처, 사용자 입력(조항·구간·쟁점) 양식, Claude 초안 작성, HWP 양식 1종 채우기
- **P1:** 양식 여러 종 + 양식 선택, CSV 사례 검색, 타임코드·인용 대조표
- **P2:** 엑셀 갱신 시 CSV 자동 변환·중복 확인, 긴 영상 처리 개선
- **1차 제외:** 위반 여부 자동 판단, 로컬 AI·모델 선택, 화면 OCR, 여러 영상 일괄 처리, 별도 화면(GUI)

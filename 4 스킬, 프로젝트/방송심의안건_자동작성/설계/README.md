## 스킬 시험에서 찾은 개선점 (automation-spec-builder v1.1 → v1.2에 반영함, 2026-11-25. 06 문서 5절의 7개와 함께)

1. **기본 저장 위치 충돌:** `Claude outputs\자동화설계\`는 AGENTS.md 2절("스크립트와 그 설명만")과 맞지 않음 → 도구 폴더 `4 스킬, 프로젝트\<도구명>\설계\`로 바꿀 것
2. **질문 선택지 편향:** "무엇을 자동화할지"만 선택지로 줘서 사용자가 직접 답을 써야 했음 → "사람이 정할 것 / AI가 할 것" 경계를 묻는 질문을 따로 둘 것
3. **시험 모드 없음:** "기존 도구 무시" 같은 조건을 받는 방법이 없음 → 0단계에 건너뛰기 조건과 브리프 표기 방법 추가
4. **환경 점검을 직접 실행한 것이 유용:** 설치 패키지·FFmpeg·한글 COM을 실제로 확인해 [검증 완료]로 바꿨음 → 6단계에 "로컬 환경은 명령으로 직접 확인" 명시
5. **템플릿이 웹앱 중심:** 스크립트+스킬형에서는 16·20·24~30·41절이 해당 없음이거나 바꿔 써야 했음 → 실행 형태별(웹앱 / 스크립트·스킬형) 절 선택 안내 추가
6. **견본 없이 상세 설계:** 핵심부(양식 입력·사례 열)가 TODO로 남음 → 브리프에서 견본을 받으면 설계 정확도가 크게 오른다고 알리고, 견본 없이 진행할지 묻기
7. **분량:** 상세 설계서가 길어짐(55절) → Standard에서 해당 없는 절은 한 줄로 묶는 규칙 추가 검토

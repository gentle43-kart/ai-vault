# 입력 템플릿 — 민원 검토 요청 양식

> 아래 양식을 복사해 채워 넣고 대화창에 붙여넣는다. 채울 수 없는 항목은 "미상"으로 둔다.
> 방송내용(녹취/자막/영상 설명)이 **가장 중요**하다. 이것이 없으면 정확한 검토가 불가하며, 지어내지 않고 정보 요청으로 되돌아간다.

---

```
[민원 검토 요청]

■ 채널명:
■ 프로그램명:
■ 방송일시: (YYYY.M.D. HH:MM)
■ 프로그램 성격: (예: 시사·대담 / 뉴스보도 / 드라마 / 예능·오락 / 교양 / 건강정보 …)
■ 시청등급: (해당 시)
■ 생방송 여부: (생방송 / 녹화)

■ 민원(심의요청) 요지:
   - (민원인이 무엇을, 어느 규정 위반이라 주장하는지)
   - 기관민원 여부 / 기관명:
   - 동일·유사 민원 건수:

■ 방송내용 (녹취 / 자막 / 장면 설명):
   - (문제된 발언·장면을 가능한 한 그대로. 앞뒤 맥락·상반 발언·자막·자료화면 포함)

■ 참고자료 (선택):
   - (언론보도, 당사자 입장, 관련 판례·심의사례, 시청등급 고지 여부 등)
```

---

## 요청 시 얻게 되는 출력
1. **유형 분류 결과** (결정트리 판정) + 근거
2. **핵심 쟁점** (민원 주장 ↔ 적용 심의규정)
3. **검토의견 초안** (복사 가능한 완성형) — 어떤 면책요소를 방송내용의 어디에서 근거했는지 각주
4. 필요 시 **⚠️ 심의안건 상정 검토 필요** 플래그 + 사유

## 팁
- 여러 건을 한 번에 넣어도 되지만, 건별로 위 블록을 반복한다.
- 방송내용이 길면 문제 구간 위주로 발췌하되 **앞뒤 맥락**을 반드시 포함(맥락이 면책논거의 핵심).
- "이건 위반인지 아닌지 애매하다" 싶은 사안은 그렇게 적어달라 — 억지 면책논리 대신 상정 검토 플래그로 판단해 준다.

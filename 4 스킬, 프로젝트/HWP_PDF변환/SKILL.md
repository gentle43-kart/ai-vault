# 한글 → PDF 일괄 변환 (한컴 엔진)

도구 폴더: `J:\AI 자료\4 스킬, 프로젝트\HWP_PDF변환` (이 스킬의 정본 SKILL.md·CHANGELOG.md도 이 폴더에 있다)
- `SOURCE\` : 사용자가 변환할 HWP·HWPX를 넣는 곳(하위 폴더 포함)
- `OUTPUT\` : PDF 저장 위치(SOURCE의 폴더 구조 그대로) + `변환로그_날짜.csv`
- `hwp_to_pdf.py` : 변환 스크립트, `HWP_PDF_변환.cmd` : 사용자가 더블클릭으로 직접 실행하는 파일

## 실행
```powershell
cd 'J:\AI 자료\4 스킬, 프로젝트\HWP_PDF변환'
py -3.12 hwp_to_pdf.py
```
- 옵션: `--force`(OUTPUT에 같은 이름 PDF가 있어도 다시 변환), `--src <폴더> --dst <폴더>`(다른 폴더 지정).
- 기본은 이미 있는 PDF를 **건너뛴다**. 덮어쓰기(`--force`)는 사용자에게 묻고 쓴다.
- 한 파일당 수 초. 파일이 많으면(대략 30개 이상) 백그라운드로 실행한다.
- 실행 중 한글 창이 떠 있다(창을 숨기면 열기에서 멈추는 경우가 있어 일부러 숨기지 않음). 사용자가 쓰던 한글은 건드리지 않고, 스크립트가 띄운 한글만 끝에 정리한다.

## 실행 후 보고
- 콘솔 끝줄(성공/건너뜀/실패 수)과 로그 CSV의 실패 행(파일명·사유)을 보여준다.
- 실패 사유가 '문서를 열지 못함'이면 배포용·암호·손상 문서일 가능성을 알린다. 암호를 우회하지 않는다.
- 필요하면 PDF 메타데이터 Producer가 `Hancom PDF`인지 pypdf로 확인할 수 있다.

## 주의
- SOURCE의 원본은 수정·삭제·이동하지 않는다. OUTPUT 정리(삭제)는 사용자 요청이 있을 때만 한다.
- 보안 승인 창이 계속 뜨면: 레지스트리 `HKCU\Software\HNC\HwpAutomation\Modules\FilePathCheckerModule` 값이 가리키는 DLL이 실제로 있는지 확인한다(2026-11-25 기준 등록 경로에 DLL이 없으나 승인 창 없이 변환됨). 레지스트리 수정은 사용자 승인 후.

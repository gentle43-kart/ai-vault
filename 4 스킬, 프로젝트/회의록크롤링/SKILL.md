# KOCSC 회의록 크롤러 실행

kenny430이 "회의록 크롤링해줘", "이번달 방송심의소위 회의록 받아줘" 같은 요청을 하면, 이미 준비되어 있는 `kocsc_downloader.py`를 실행해서 방송미디어통신심의위원회(KOCSC, kocsc.or.kr) 게시판에서 회의록 첨부파일(PDF)을 다운로드한다.

## 스크립트 위치

연결된 폴더 안에 있다 (정확한 마운트 이름은 세션의 connected folder 목록을 device_list_dir로 확인):

```
D:\9 claude\워크_1\회의록크롤링\회의록 크롤링\kocsc_downloader.py
```

이 스크립트는 원래 사용자가 직접 만든 것이며, 2026-09에 Claude가 `--boards` / `--start` / `--end` / `--output-dir` CLI 인자를 추가해서 비대화형(non-interactive) 실행이 가능하도록 개선했다. 인자를 하나도 안 주면 기존처럼 `input()`으로 대화형 실행된다.

## 게시판 키와 저장 폴더

모든 파일은 스크립트 폴더 아래 `downloads`에 게시판별 하위 폴더로 저장된다.

| 키 | 게시판 | 저장 폴더(downloads 아래) | 첨부 선뱄 규칙 |
|---|---|---|---|
| 1 | 위원회회의(전체회의) 회의록 | `전체회의 회의록` | "발언내용" 첨부만, 없으면 의결서 제외한 첫 파일 |
| 2 | 방송심의소위원회 회의록 | `방송심의소위원회_회의록` | 첨부 전부 |
| 3 | 통신심의소위원회 회의록 | `통신심의소위원회_회의록` | 첨부 전부 |
| 4 | 광고심의소위원회 회의록 | `광고심의소위원회_회의록` | 첨부 전부 |
| 0 또는 all | 전체 | — | — |

여러 유형은 쉼표로 연결한다(예: 방송+통신 → `2,3`). 이미 같은 이름으로 저장된 파일은 건너뛰고, 기존 파일은 삭제하지 않는다.

## 실행 전 반드시 확인할 것

1. **게시판 종류**: 요청에 명시되지 않았으면 물어본다(전체회의/방송심의소위/통신심의소위/광고심의소위 중 어느 것인지, 아니면 전체인지).
2. **기간(start/end)**: "이번달/지난주/8월" 등은 오늘 날짜(Asia/Seoul 기준)로 YYYY-MM-DD로 환산한다. 기간이 전혀 없으면 반드시 물어본다(임의로 넓게 추측해 실행하지 않는다). 이미 받은 파일은 스킵되므로 기간을 다소 넓게 잡아도 중복 부작용은 없다.

## 실행 방법 (기본: 사용자 로컬 직접 실행)

이 크롤링은 사용자 컴퓨터의 네트워크로 파이썬이 실행되어야 한다. 세션마다 device_bash 동작 여부를 먼저 확인해서 경로를 정한다.

1. **device_bash(로컬 셀)가 정상이면** 그것으로 직접 실행한다:
   ```
   cd "$HOME/mnt/회의록 크롤링"   # 실제 마운트 이름은 device_list_dir로 먼저 확인
   python kocsc_downloader.py --boards <키> --start <YYYY-MM-DD> --end <YYYY-MM-DD>
   ```
   다운로드된 파일은 스크립트가 사용자 컴퓨터에 직접 저장하므로 device_commit_files를 따로 쓸 필요가 없다.

2. **device_bash가 실패하면** (2026-09 현재 Windows KB5124008 버그로 `sandbox-helper: no Plan9 drive shares mounted` 오류), Claude가 직접 실행할 수 없다. 이때는 사용자에게 **복사해 바로 붙여넣을 수 있는 완성된 명령어**를 제시하고 해당 폴더의 로컬 터미널(PowerShell/CMD)에서 직접 실행하도록 안내한다. 예:
   ```
   cd "D:\9 claude\워크_1\회의록크롤링\회의록 크롤링"
   python kocsc_downloader.py --boards 2 --start 2026-09-01 --end 2026-09-11
   ```
   이 방식이 ChatGPT/Codex가 동작하는 방식과 동일하며(사용자 네트워크 + 로컬 파이썬), 토큰 낭비 없이 하위폴더 분류까지 자동으로 된다.

### 왜 그런가 (배경)
- Claude의 클라우드 컨테이너 Bash는 kocsc.or.kr 접속이 조직 egress 정책으로 차단된다(403, 확인됨). 따라서 클라우드에서는 이 스크립트를 돌려도 다운로드가 안 된다.
- device_bash(로컬 셀)만이 사용자 네트워크로 파이썬을 돌릴 수 있는데, 2026-09 Windows 업데이트(KB5124008)가 Plan9 마운트를 깨뜨려 사용 불가한 시기가 있다. 이건 이 스크립트나 작업의 문제가 아니라 디바이스 브릿지 자체의 알려진 장애이니 재시도로 해결하려 하지 말고 사용자에게 그렇게 설명한다.
- Chrome/Chrome 확장은 이 파이썬 크롤러의 네트워크 차단과 무관하므로 해결책이 아니다(검토 완료).

## 완료 후 보고

대상 기간·회의 유형·저장 경로를 알리고, 실제 결과에서 확인된 파일 수만 보고한다(device_bash 직접 실행 시 stdout의 "게시글 N건, 첨부파일 M건" 요약 그대로; 사용자 로컬 실행 시 사용자 보고 기준). 사이트 구조나 다운로드 방식이 바뀌어 오류가 나면 kocsc_downloader.py를 먼저 확인하고, 첨부파일 선뱄 규칙은 유지한다.

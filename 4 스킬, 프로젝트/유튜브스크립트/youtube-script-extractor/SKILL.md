# 유튜브 스크립트 추출

kenny430이 유튜브 주소를 주면서 "스크립트 따줘", "자막 추출해줘", "이 영상 내용 분석해줘" 같은 요청을 하면, 사용자 PC에 설치된 `video_to_script.py`로 만든 텍스트를 읽어 작업한다.

## 도구 위치

```
J:\AI 자료\4 스킬, 프로젝트\유튜브스크립트\
  video_to_script.py   추출 스크립트(v2, 2026-11-19)
  run.bat              더블클릭 → 주소 붙여넣기 → 실행
  install.bat          최초 1회 패키지 설치(Python 3.12)
  output\              결과 저장 폴더
```

결과 파일 이름은 `게시일_제목_영상ID.txt`(구간별 타임스탬프 원본)와 `게시일_제목_영상ID_문단.txt`(약 30초 단위 문단본)이다. 두 파일 맨 위에 제목·채널·게시일·영상 길이·추출 방식이 `# ` 줄로 적혀 있다.

## Claude가 직접 실행하지 않는 이유

2026-11-19 확인 결과, 클라우드 작업 공간(Bash)과 PC의 Claude 셸(device_bash, Linux VM) 모두 youtube.com과 huggingface.co(Whisper 모델) 접속이 차단된다. device_bash는 Windows의 Python 3.12도 실행할 수 없다. 따라서 추출은 사용자가 PC에서 실행하고, Claude는 결과 파일만 읽는다. 차단 여부를 확인하려고 재시도를 반복하지 않는다.

## 절차

1. **영상 ID 확인**: 주소에서 11자리 영상 ID를 뽑는다(`v=`, `youtu.be/`, `shorts/`, `live/`, `embed/` 뒤).
2. **기존 결과 확인**: `output` 폴더에 그 영상 ID가 들어간 파일이 있는지 device_list_dir로 확인한다. 폴더가 세션에 연결되어 있지 않으면 `J:\AI 자료\4 스킬, 프로젝트` 접근을 device_request_folder_access로 요청한다. 있으면 4단계로 간다.
3. **실행 안내**: 없으면 아래처럼 복사해 바로 붙여넣을 수 있는 명령을 제시하고, 완료되면 알려 달라고 한다.
   ```
   cd "J:\AI 자료\4 스킬, 프로젝트\유튜브스크립트"
   py -3.12 video_to_script.py "<유튜브 주소>"
   ```
   더블클릭을 선호하면 `run.bat` 실행 후 주소를 붙여넣으라고 안내한다. 옵션은 상황에 맞을 때만 덧붙인다: 자동 자막 품질이 나쁘면 `--whisper`, 정확도가 더 필요하면 `-m large-v3`, 자막 파일이 필요하면 `--srt`.
4. **결과 읽기**: 분석·요약에는 `_문단.txt`를 읽는다(device_bash의 `cat` 또는 device_stage_files). 대사를 정확히 인용하거나 시점을 특정해야 할 때만 원본 `.txt`의 해당 구간을 grep으로 찾아 읽는다. 전체 원본을 통째로 읽지 않는다.
5. **결과 보고**: 먼저 헤더의 제목·채널·게시일·추출 방식(수동 등록 자막 / 자동 생성 자막 / Whisper)을 한 줄로 알린 뒤, 요청받은 분석을 진행한다.

## 업무 활용 시 주의

- 자동 생성 자막과 Whisper 결과는 기계 전사본이다. 안건·의결서·개선계도문 초안에 대사를 인용할 때는 해당 타임스탬프를 함께 적고, 원 영상과 대조하지 않은 인용에는 `[확인 필요: 원 영상 대조, 00:12:34]`처럼 표시한다. 수동 등록 자막도 실제 방송 발언과 다를 수 있으므로 같은 원칙을 적용한다.
- 화자 구분이 되지 않는다. 진행자·출연자를 구분해야 하면 문맥으로 추정한 부분을 추정이라고 밝히고, 필요하면 클로바노트 병행을 제안한다.
- 유튜브 게시본은 방송 원본과 편집·길이가 다를 수 있다(클립, 하이라이트). 심의 대상 방송분과 같은지 확인이 필요하면 그 점을 알린다.
- 스크립트 수정·기능 추가 요청은 Claude Code에서 진행하도록 권한다.

## 오류 대응

사용자가 오류 메시지를 전하면 원인별로 안내한다.

| 증상 | 조치 |
|---|---|
| `No module named ...` | `install.bat` 실행 또는 `py -3.12 -m pip install -U faster-whisper youtube-transcript-api yt-dlp` |
| 자막 가져오기 실패 후 다운로드 단계에서 오류 | YouTube 변경 가능성이 크므로 `py -3.12 -m pip install -U yt-dlp youtube-transcript-api` 후 재실행 |
| `[자막 가져오기 실패] RequestBlocked/IpBlocked` | 사무실 네트워크 차단 가능성. 자동으로 Whisper로 넘어가므로 기다리면 됨 |
| Whisper 단계가 매우 오래 걸림 | CPU 실행이면 정상(영상 길이 이상 걸릴 수 있음). 급하면 `-m small` |
| `cudnn`·`cublas` DLL 오류 | 스크립트가 CPU로 자동 재시도함. 그래도 실패하면 오류 전문을 받아 확인 |
| `py`를 찾을 수 없음 | `"C:\Program Files\Python312\python.exe" video_to_script.py "<주소>"`로 실행 |

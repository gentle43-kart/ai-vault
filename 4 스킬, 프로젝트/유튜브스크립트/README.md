# 유튜브 스크립트 추출기

방송 프로그램 영상의 대사를 텍스트로 뽑아 안건 작성·심의 검토에 쓰기 위한 도구입니다.
Claude의 작업 공간에서는 YouTube 접속이 차단되어 있으므로, 이 PC에서 직접 실행합니다.

## 처음 한 번
`install.bat`을 더블클릭합니다(Python 3.12에 faster-whisper, youtube-transcript-api, yt-dlp 설치).

## 사용
- 더블클릭: `run.bat` → 유튜브 주소를 붙여넣고 Enter
- PowerShell: `py -3.12 video_to_script.py "유튜브주소"`
- 옵션
  - `--whisper`: 자막이 있어도 음성 인식 사용(자동 자막 품질이 나쁠 때)
  - `-m large-v3`: 더 정확한 인식 모델(더 느림, 기본 medium)
  - `--srt`: SRT 자막 파일도 생성
  - 로컬 영상 파일도 가능: `py -3.12 video_to_script.py "D:\영상\파일.mp4"`

## 결과 (output 폴더)
- `게시일_제목_영상ID.txt`: 구간별 타임스탬프 원본(인용 위치 확인용)
- `게시일_제목_영상ID_문단.txt`: 약 30초 단위 문단본(Claude 분석용)
- 파일 맨 위에 제목·채널·게시일·추출 방식(수동 자막 / 자동 생성 자막 / Whisper)이 적힙니다.

## 방송 영상 → 화면 캡처 + 타임라인 (video_to_draft.py)
심의안건 '방송내용' 초안용입니다. 로컬 영상(mp4·wmv 등)에서 장면 전환·일정 간격 프레임을 저장하고, 전사본을 프레임 구간별로 붙입니다.
- 실행: `py -3.12 video_to_draft.py "D:\영상\파일.mp4"`
- 결과(`output\<영상이름>\`): `frames\fNNN_시-분-초.png`, `<영상이름>.txt`, `<영상이름>_문단.txt`, `timeline.md`
- 옵션
  - `-m medium`(기본) / `-l ko`(기본)
  - `--interval 4`: 장면 전환이 없어도 이 초 간격으로 프레임 저장(자막 누락 방지)
  - `--scene-threshold 30`: 장면 전환 판정 기준(낮을수록 프레임 증가)
  - `--min-gap 1`, `--max-frames 200`, `--width 960`
  - `-d 폴더`: 출력 상위 폴더(기본 `output`)
  - `--force`: 같은 출력 폴더가 있으면 묻지 않고 덮어씀(없으면 물어보고, 답할 수 없는 환경에서는 중단)
  - `--no-transcribe`: 전사 없이 프레임만(설정 조정용)
  - `--start`, `--end`(v2): 긴 영상에서 구간만 처리. 초(`90`), 분:초(`1:30`), 시:분:초(`01:02:03`). 프레임은 그 위치로 건너뛰어 읽고, Whisper도 구간만(앞뒤 5초 여유, 최소 30초 단위로 인식한 뒤 구간 안만 남김) 인식합니다. 결과 폴더 이름에 `_구간시-분-초~시-분-초`가 붙어 전체 처리 결과를 덮어쓰지 않습니다.
  - `--transcript 파일`(v2): 클로바노트 등 외부 전사본(txt·srt)을 읽어 Whisper를 건너뜁니다. 지원 형식은 `참석자 1 00:03` 줄 + 본문, `[00:00:03] 본문`, SRT(UTF-8·CP949). 시각이 없으면 거부합니다.
  - 예: `py -3.12 video_to_draft.py "영상.mp4" --start 00:12:00 --end 00:15:30 --transcript 클로바.txt`
- 참고(2026-11-22): 39초 뉴스 단신 기준 프레임 14장, medium 전사 포함 약 35초(CPU). 1시간 영상 전체를 기본값으로 돌리면 프레임 상한(200장) 때문에 간격이 18~36초로 벌어지므로, 쟁점 구간을 정해 `--start/--end`로 처리하는 것이 좋습니다.
- v2 시험(2026-11-22, 79초 영상): 구간 프레임 추출(20~30초, 0.5초 간격 20장), 외부 전사본 4형식 파싱(클로바 형식·`[시각]`·SRT·CP949)과 시각 없는 파일 거부, 구간 Whisper(14~34초, 40~58초) 확인. 1시간짜리 영상과 실제 클로바노트 내보내기 파일로는 아직 시험하지 않았습니다.
- 이전 판(v1) 백업: `backup\video_to_draft_v1_20261122.py`

## 주의
- **av(PyAV)는 19 미만을 유지합니다.** av 19.x는 faster-whisper 1.2.1과 맞지 않아 `metadata_errors` 오류가 납니다(2026-11-22 확인, 18.1.1 사용). `pip install -U`로 일괄 갱신하지 말고, 깨지면 `py -3.12 -m pip install "av<19"`.
- 자동 생성 자막과 Whisper 결과는 기계 전사본입니다. 의결서·안건에 인용하는 대사는 원 영상과 대조합니다.
- 화자 구분은 되지 않습니다(진행자·출연자 구분이 필요하면 클로바노트를 병행).
- 오류가 나면 먼저 `py -3.12 -m pip install -U yt-dlp youtube-transcript-api`로 갱신합니다(YouTube 변경에 맞춰 자주 갱신됨).
- 자막이 없는 영상은 Whisper로 인식하므로 CPU에서는 영상 길이만큼 이상 걸릴 수 있습니다.

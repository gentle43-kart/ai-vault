# 2026-11-13 통계 대조 열린 항목 점검

[[2026-11-12 열린 확인 항목 분류]]의 C(집계·통계 근거)·E(회의록·의결 사례 조사) 열린 항목을 `query_decisions`(MCP v1.17)로 다시 점검했다. 읽기 전용 점검이며 위키 페이지의 항목·수치는 고치지 않았다.

## 1. 범위와 방법

- 대상: `wiki_lint.py` v1.7의 열린 항목 637개 중 C 101 + E 140 = 241개(분류 문서는 242곳으로 셌으나 그 뒤 하나가 닫힘). 단위는 항목(체크박스 한 줄).
- 검증값: `query_decisions` 응답의 검증값(기본 범위 12,560행, 방송심의규정 제46조 1,351·제44조 760·제27조 777·제14조 1,117·제9조 332) 일치를 확인한 운영 DB에서 실행.
- 사용 도구: 집계는 `decision_query.query()`(unit=row, scope=all)를 직접 불러 계산했다. MCP 도구와 같은 코드이다.

## 3. 방송심의 120개 항목

- **수치·기간 주장 점검(31건)**: 항목 문장에 적힌 행 수("적용 27행")나 "적용 행이 없다"는 기간 주장을 도구로 다시 세었다. 일치 30건, 비교 불가 1건(아래 표). 어긋난 수치는 없었다.
- 나머지 항목은 대부분 "이유·배경·경과"(회의록 조사), 개별 안건 내용 확인, 의결서 원문, 외부 유권해석이다. 숫자를 다시 세어도 닫을 수 없다.
- "의결 내용 칸 검색"(예: "원료", "외모", "친환경")이 근거인 항목 약 15개는 도구가 의결 내용 칸을 검색하지 못해 이번에는 점검하지 못했다.

## 4. 중요한 발견: 위키 조 번호와 통계 CSV 조 번호가 다르다

위키 조문 페이지 이름은 2026.9.29. 시행 새 규칙(방송심의규정 제8호, 광고심의규정 제10호)의 번호이고, 통계 CSV의 관련조항 칸은 2026.9.28.까지 구 번호(제150·151호)이다(AGENTS_통계기준.md 7.1절). 그래서 `query_decisions`에 페이지의 조 번호를 그대로 넣으면 다른 조의 행이 나온다. 예: 위키 광고심의규정 제48조는 구 제40조이고, 같은 번호로 조회하면 0행이다.

- 이번 점검은 [[조문 시기 대응표]] 2A절로 위키 번호를 구 번호에 바꿔 조회했다(표 "비교 번호"). 항목 문장의 수치는 모두 이 방식으로 일치했다.
- 〔추론〕 도구 사용 규칙(AGENTS.md 6.1절)은 이 변환을 모른다. 위키 질문을 도구로 답할 때 구 번호로 바꾸는 단계를 도구가 맡는 편이 안전하다(`query_decisions`에 현행 번호 기준 옵션 추가 제안, 승인 후 반영).

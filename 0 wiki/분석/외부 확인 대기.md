# 외부 확인 대기

각 위키 페이지의 "추가 확인 필요" 절에서, 사용자가 자료를 넣어 주거나 확인해 주기 전에는 Claude가 닫을 수 없는 항목을 한 곳에 모은 목록이다(AGENTS_절차.md 6.6절, 사용자 선택 2026-11-13, 사용자 확인 2026-11-13). 판례·소송 결과, 자료창고에 없는 원본·의결서·개정 사유서, 사무처 내부 문서, 유권해석, 사용자 판단 항목이 대상이다.

- 형식: `- [ ] (페이지 위키링크) 절: 요지 — 필요한 확인 — 등재일`. 해결되면 `[x]`로 바꾸고 해결 내용과 일자를 덧붙인다.
- 각 페이지의 "추가 확인 필요" 절에는 `- [→] 요지 → [[외부 확인 대기]]` 한 줄이 남는다. `wiki_lint.py`는 `[→]`를 열린 항목에서 빼고 `external_wait`로 따로 센다.
- 이동 기준: 항목 문장의 키워드로 가려낸 기계 분류이며 경계 항목은 달라질 수 있다(법령 원문이 근거인 항목은 법령 MCP로 확인할 수 있으므로 옮기지 않았다).
- `classification: internal` 페이지의 항목(판결·소송 11개)은 internal 자료의 내용을 목록으로 옮기지 않으려고 이동하지 않았고 각 페이지에 남아 있다(AGENTS.md 8절).
- 해결된 항목의 반영: 해결되면 해당 페이지의 `[→]` 줄을 지우거나 결과 서술로 바꾸고 이 목록 항목을 `[x]`로 바꾼다. 페이지 내용 수정이므로 사용자 확인 뒤에 한다.

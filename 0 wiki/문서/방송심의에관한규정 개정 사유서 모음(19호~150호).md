# 방송심의에관한규정 개정 사유서 모음(19호~150호)

## 1. 문서 정보

- 종류: 「방송심의에 관한 규정」 제정 공고문과 개정 공고문, 개정이유·주요내용을 판별로 모은 PDF(위원회 제공 자료)
- 기준일: 2020-12-28(수록된 마지막 판인 제150호의 공고일)
- 분량: PDF 112쪽(제123호 제외본) + 제123호 추가자료 PDF 3쪽. 통합·중복제거 MD 변환본은 3,383줄이며 `<!-- PDF p. N -->` 표시로 쪽을 보존함. 제123호 추가자료는 3008~3121행에 `<!-- 제123호 추가자료 PDF p. N -->` 표시로 들어 있음
- 파일 교체 이력(2026-09-23): 사용자가 제123호 사유서를 보완해 MD를 `…_제123호통합.md`로, 원본 PDF를 `…_123호 제외.pdf`와 `…_제123호 추가.pdf`로 나누어 올림. 이어서 제121호 중복분(PDF p.103~105)을 뺀 MD `…_제123호통합_중복제거.md`로 다시 교체함(원본 PDF는 중복이 남은 그대로 보존). 이 위키 페이지 이름은 최초 파일명을 유지함(이름 변경은 사용자 확인 사항)
- registry_id: `law_broadcast` (MD 파일은 `1 documents_md/법령_md/방송_md/`, 원본 PDF는 같은 등록 항목의 raw 폴더 아래 `규정 연혁/`에 있음)
- 기존 자료와의 관계: 같은 기간을 다룬 「제정·개정문(사유) 모음」(법제처 제개정문을 모은 MD, 이하 "제정·개정문 모음")과 독립된 별개 자료다. 두 자료의 대조 결과는 3절에 정리했다.

## 2. 핵심 요지

제19호(2008 제정)부터 제150호(2020)까지 공고문과 개정이유를 수록했다. 제30호~제150호의 개정문·개정이유는 제정·개정문 모음과 실질 내용이 같다. 제정·개정문 모음에 없는 제19호 제정 전문과 제55호·제80호 개정 후 전문이 들어 있다. 제123호는 별도 추가자료로 보완되었고(제정·개정문 모음과 내용 일치), 제121호 중복은 MD에서 제거되었다(원본 PDF에는 남아 있음). 제55호와 제109호의 공고일은 제정·개정문 모음과 다르며, 사용자 확인으로 사유서 쪽 날짜(2010.2.17., 2014.12.31.)를 따른다.

- 제123호 보완 경과(2026-09-23): 처음 제공된 "제123호.pdf"(3쪽)는 공고일(2016.8.3.)과 내용으로 보아 제121호 사유서였다. 이후 사용자가 제123호(공고 제2016-17호, 2016.12.28.) 사유서를 별도 PDF로 추가하고 MD에 통합했다. 제121호 중복 수록(p.100~102, p.103~105)은 이후 중복제거 MD에서 해소되었다(원본 PDF에는 남아 있음).
